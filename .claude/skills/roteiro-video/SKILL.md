# Roteiro de vídeo

1. Leia `conhecimento/perfil-da-conta.md`, `conhecimento/resumos/INDICE.md` e, se existir,
   `produtos/<produto>.md`. Se o produto não foi analisado, faça uma análise rápida antes (dor + ângulo).
2. Escolha os frameworks de copy dos cursos adequados ao ângulo (ex.: gancho, PAS, AIDA, storytelling,
   quebra de padrão — use os nomes e regras do jeito que aparecem nos resumos).
3. Para cada roteiro entregue:

```markdown
## Roteiro N — <ângulo> | Framework: <nome (curso)>
Formato: <POV / demonstração / unboxing / antes-depois / storytime / review sincero / problema-solução>
Duração: <15–45s>

**Gancho (0–2s)** — fala: "..." | texto na tela: "..." | visual: ...
**Variações de gancho:** 1) ... 2) ... 3) ...

| Tempo | Cena / o que aparece | Fala | Texto na tela |
|---|---|---|---|
| 0–2s | ... | ... | ... |
| ... | ... | ... | ... |

**CTA:** "..." (ex.: "toca no carrinho laranja")
**Legenda + hashtags:** ...
**Por que funciona:** 1–2 linhas ligando ao framework do curso.
```

4. Padrão: entregue 3 roteiros com ângulos diferentes + 10 ganchos extras.
5. Regras: o produto aparece resolvendo a dor nos primeiros 5s; frases curtas e faladas; um único CTA;
   nada que viole as políticas do TikTok Shop (ver CLAUDE.md).
6. Salve em `conteudos/roteiros/<produto>-<data>.md`.
